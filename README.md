# EasyRPG-Arabic

EasyRPG-Arabic makes RPG Maker 2003 + Maniacs practical for creating Arabic games.

## Screenshots

![Arabic dialogue and choices](docs/screenshots/arabic-dialogue.png)

## Features

- Arabic typing in the Maniacs editor
- RTL / BiDi / Arabic shaping
- Windows-1256 / CP1256 project support
- Moroccan Darija system translation
- BOU33OU Arabic PixelSmall font
- EasyRPG Player integrated automatically
- 426×240 widescreen support

## Install

1. Install RPG Maker 2003 from Steam.
2. Download `EasyRPG-Arabic-Setup.exe` from the latest release.
3. Provide the supported official Maniacs package when Setup asks for it.
4. Setup creates the managed Arabic environment under:

   `<RPG Maker 2003>\Arabic`

5. Open the Arabic Maniacs editor and create a new project.

That's it.

New projects are automatically prepared with:

- Arabic font
- Darija PO translation base
- EasyRPG-Arabic `Player.exe`
- CP1256 configuration
- 426×240 widescreen configuration
